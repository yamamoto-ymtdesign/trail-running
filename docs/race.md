## 目標タイム（2026-10-05 設定）

「中盤より上」＝完走者の **上位40%以内** とする。

2027年はコースが 46km → 50km に延び、累積標高も約3,000m（未確認）になる見込み。km-effort（距離 ＋ 累積標高÷100）は 74 → 約80 で、**約1.08倍**。2026年のタイムをこの比で換算した。

| 目標 | 2026年コースなら | **2027年（換算）** |
|---|---|---|
| 挑戦（上位25%） | 7:23 | **8:00** |
| **目標（上位40%）** | 7:52 | **8:30** |
| 最低ライン（中央値） | 8:14 | **8:55** |

注意点：
- 2027年の累積標高とコースが公式に出たら、換算をやり直す
- 第2回は ITRA ポイントが付くため、参加者のレベルが上がる可能性がある。目標を上位40%にしているのは、その余裕も見込んでいる
- 3月開催（2026年は4月）なので、気温が低い。暑さの影響は小さくなるが、山の凍結に注意

## 現在の走力との差

km-effort あたりのペースで比べる。

| | km-effort | タイム | 1km-effortあたり |
|---|---|---|---|
| 2026/10/3（26km・D+2,400m） | 50 | 5:10 | 6.2分 |
| 2023/4 六甲（43km・D+3,000m） | 73 | 8:30 | 7.0分 |
| 目標（2027・約80） | 80 | 8:30 | **6.4分** |

- いまの力で2026年のコースを走ると、7.0〜7.5分/km-effort として **8:38〜9:15**。順位では **上位59〜72%** あたりで、中盤よりやや下になる
- 目標の 6.4分/km-effort は、10/3 の 26km（6.2分）とほとんど同じ。10/3 のペースを最後まで保てれば、2026年のコースで 7:39（上位32%相当）になる。**足りないのはスピードではなく、その速さを 50km の最後まで保つ力**。計画で、後半の下りに耐える脚と量を優先しているのはこのため

## ペース配分（2027年の目安）

2027年のエイド位置はまだ分からないので、上位40%グループの配分（2026年）をそのまま当てはめる。

| 区間 | 全体に占める割合 | 目標8:30の場合 |
|---|---|---|
| スタート → A1 | 約30% | 2:33 |
| A1 → A2 | 約17% | 4:00 |
| A2 → A3 | 約19% | 5:37 |
| A3 → A4 | 約17% | 7:04 |
| A4 → ゴール | 約17% | 8:30 |

2027年のコースとエイドが発表されたら、区間ごとの km-effort で配分し直す。

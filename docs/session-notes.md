Claude Code のセッションで話し合って決めたことのうち、他の文書（ランナー情報・大会情報・計画）に書いていない経緯や理由をまとめる。記録アプリの「Claudeに質問」は、この文書と他の文書を合わせて読んで答える。

## ユーザーの好み

- 答えが明確な質問にはすぐ答える。正解のない相談は、答える前に目的を確認する
- 確実でない情報には出典を付ける
- 過剰に同調しない。必要なときは批判的な視点からも助言する
- 返答は日本語

## 他のAIの元計画から変えた点と理由

- 距離ではなく時間と累積標高で管理する：トレイルでは同じ距離でも負荷が大きく違うため
- ロング走は「直近30日の最長の1.1倍以内」：1回の距離を急に伸ばすと故障リスクが上がるという研究（Frandsen et al. 2025, BJSM）があるため。研究は距離で測っており、時間に置き換えるのは推論
- 前半のロングは3〜3.5時間に抑える：ロングの時間はすでにある程度耐えられる（10/3に5時間10分）。足りないのは週の量（約15km/週）なので、平日の量を優先する
- 膝と太もも前を最優先で鍛える：ロングで膝と太もも前にダメージが出る、という本人の申告と、本番の勝負どころが急な下りであるため
- 筋トレは週1回から週2回へ：40代で筋力が落ちやすく、WHOも成人に週2日以上の筋トレを勧めているため
- 定点テスト（里山の登りタイム）を追加：伸びを測り、計画を直す根拠にするため
- 元の計画にあった「累積標高 約2,400m」は誤り。2027年ロングは D+2,850m

## 評価のまとめ（10/5時点）

- 強み：長い時間を登り続ける力はある（10/3 は 6.2分/km-effort）
- 弱み：週の量が少ない。後半の下りで膝と太もも前が持たない
- いまの力の予測：2027年コースで 9:08〜9:47（中盤よりやや下）
- 目標の 6.4分/km-effort は 10/3 のペースとほぼ同じ。課題はスピードではなく、そのペースを後半まで保つこと

## アプリと運用

- 毎日：アプリで体調（疲れ、太もも前、膝と痛む場所、睡眠）を記録
- 練習後：時間・距離・D+・きつさ。ロング走は補給量も
- 週末：Claude Code に「今週のレビューをして」と頼む。Claude が記録を読み、来週の計画を直し、アプリとリポジトリを更新する
- いつでも：アプリの「Claudeに質問」で質問できる。この文書と計画・大会情報、最新の記録から先に答え、なければ一般的な知識で答える。質問と回答はアプリに保存され、週末のレビューでも参考にする
- アプリの質問欄では計画そのものは変えられない。計画の変更は週末のレビューで Claude Code に相談する

## 時計とデータ

- Amazfit Band 7 は GPS 非内蔵で、スマホの GPS を借りる。山では距離と累積標高がずれやすい
- intervals.icu は Zepp と連携できる。ただしこの作業環境からは接続できない。自動取り込みには、環境設定で intervals.icu を許可し、APIキーを用意する必要がある

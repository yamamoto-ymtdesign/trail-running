# WAKE ALPS TRAIL 2027 トレーニング

2027年3月22日の WAKE ALPS TRAIL ロング（49.8km・D+2,850m・岡山県和気町）で、完走者の上位40%以内に入るためのトレーニング管理。

**目標タイム 8:20**（挑戦 7:50／最低ライン 8:45）。根拠は [大会情報](docs/race.md)。

## 使い方

| いつ | やること | どこで |
|---|---|---|
| 毎朝（30秒） | 起きてすぐ・練習の前に体調を記録：疲れ、太もも前、膝、睡眠、安静時心拍 | [記録アプリ](https://claude.ai/artifact/7F9kUnmVaVrY7rLQzZDsDq) の「体調」 |
| 練習のあと（1分） | 時間・距離・D+・きつさを記録。ロング走は補給も | 記録アプリの「練習」 |
| 週末 | Claude に「今週のレビューをして」と頼む | このプロジェクトの Claude Code セッション |
| 月1回 | 里山の定点テスト（W2・W6・W10・W15・W19） | 記録アプリのメモ欄にタイムを書く |
| いつでも | 計画やレースについて質問する | 記録アプリの「Claudeに質問」 |

レビューでは、Claude がアプリの記録を読んで来週の計画を直し、アプリの「今週の計画」とこのリポジトリを更新する。

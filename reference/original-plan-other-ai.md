# 50kmトレイルランニング トレーニング計画

## 1. 目標

-   レース時期：2027年3月
-   距離：約50km
-   累積標高：約2,400m
-   目標：単なる完走ではなく、できるだけ上位入賞を狙える身体を作る
-   重点：
    -   登りの出力を長時間維持する
    -   下りで脚を壊さない
    -   30km以降も動き続けられる持久力
    -   レース中の補給能力を高める

## 2. 現在の走力・条件

-   ロード10km（平地）：約50分
-   トレイル30km：約5時間
-   現在のロード走行距離：約15km/週
-   トレーニング可能日数：週4日
-   30km程度のトレイルレース経験あり

現状ではスピードそのものよりも、普段の走行量と長時間運動への耐性に大きな伸びしろがある。

------------------------------------------------------------------------

## 3. 3月までの基本方針

### 10〜11月：基礎作り

-   週4日の運動習慣を安定させる
-   イージーランを中心に有酸素能力を作る
-   筋トレを開始する
-   ロングトレイルを15〜25km程度から積み上げる
-   急激に走行距離を増やさない

### 12〜1月：登坂力・下り耐性を強化

-   週1回の坂インターバルまたはテンポ走
-   週末のトレイルを25〜35kmへ
-   累積標高を徐々に増加
-   下りの走行練習を重視
-   筋力トレーニングを継続

### 2月：レース特異的トレーニング

-   30〜35km程度のロングトレイル
-   1〜2回程度、35〜40km / D+1,800〜2,200m程度の模擬レース
-   本番装備・本番補給をテスト
-   必要に応じてバック・トゥ・バックを実施
    -   例：土曜30km＋日曜15km程度

練習で50kmを走り切る必要はない。

### 3月：テーパリング

本番2〜3週間前から走行量を減らす。

目安：

-   3週間前：通常の70〜80%
-   2週間前：50〜60%
-   レース週：30%前後

短い坂やテンポ走などの刺激は多少残し、疲労だけを抜いていく。

------------------------------------------------------------------------

## 4. 週4日の基本構成

例：

  曜日   内容                                   目的
  ------ -------------------------------------- ----------------
  月     完全休養                               回復
  火     Easy 8〜12km＋筋トレ                   有酸素＋筋力
  水     休養                                   回復
  木     坂インターバルまたはテンポ走 8〜12km   心肺・登坂力
  金     休養                                   回復
  土     ロングトレイル                         最重要練習
  日     Easy 5〜10km程度                       回復・疲労耐性

### イージーラン

現状の10km＝50分を考えると、まずはロードでおおむね6:00〜6:40/km程度を目安とする。

ただしペースを固定せず、「会話できる強度」を優先する。

### 坂インターバル

開始例：

-   アップ：2km
-   5分程度の登り × 4本
-   下りはジョグで回復
-   ダウン：2km

慣れてきたら、

-   5〜8分 × 5〜6本

程度まで発展させる。

### テンポ走

坂が確保できない場合：

-   アップ：2km
-   テンポ走：20〜30分
-   ダウン：2km

------------------------------------------------------------------------

## 5. 週走行距離の目安

現在約15km/週なので、急激に50〜60kmへ増やさない。

目安：

-   10月：20〜30km/週
-   11月：30〜40km/週
-   12月：35〜45km/週
-   1月：40〜50km/週
-   2月：45〜55km/週

毎週増やし続けるのではなく、

**3週間負荷 → 1週間軽め**

程度の周期で回復週を入れる。

最終的には週4日でも、

-   週45〜55km
-   週累積標高 D+1,500〜2,500m程度

を安定して処理できる時期を作ることを目標とする。

------------------------------------------------------------------------

## 6. ロングトレイルの発展

目安：

-   10月：15〜22km / D+600〜800m程度
-   11月：20〜25km / D+800〜1,000m程度
-   12月：25〜30km / D+1,000〜1,300m程度
-   1月：30〜35km / D+1,300〜1,800m程度
-   2月：35〜40km / D+1,800〜2,200m程度の模擬レースを1〜2回

距離だけでなく累積標高を管理する。

------------------------------------------------------------------------

## 7. 休養・回復

基本原則：

**ハード → イージーまたは休養 → ハード**

とし、ハード練習を連続させない。

目安：

-   Easy：翌日も運動可能
-   坂・テンポ：次の強い刺激まで48時間程度
-   筋トレ：同じ部位への強い負荷は48時間程度空ける
-   30km級トレイル：翌日は休養または非常に軽い運動

以下が続く場合は負荷を落とす。

-   脚の重さが抜けない
-   安静時心拍が普段より高い
-   睡眠の質が低下
-   同じペースなのに心拍が高い
-   筋肉・腱・関節などに局所的な痛みがある

メニューを消化することより、重要練習を高品質で行える状態を優先する。

------------------------------------------------------------------------

# 8. 筋力トレーニング

目的は筋肥大ではなく、

1.  登りで出力を維持する
2.  下りで大腿四頭筋を壊さない
3.  臀部・ハムストリングを強化する
4.  足首・ふくらはぎを長時間持たせる
5.  不整地でも骨盤・体幹を安定させる

こと。

基本は週1回40〜50分。

Easyの日にランニングとまとめると休養日を確保しやすい。

## 8-1. ブルガリアンスクワット

### 方法

1.  後ろ足を椅子やベンチに乗せる
2.  前脚に体重を乗せる
3.  膝とつま先を同じ方向に保つ
4.  約3秒かけてゆっくり下降
5.  下で0〜1秒停止
6.  前脚で力強く立つ

### 回数

-   8〜12回 × 3セット / 脚
-   あと1〜3回できる程度で終了

20回以上簡単にできる場合は回数を増やすより、ダンベルやリュックで荷重する。

### 目的

-   大腿四頭筋
-   臀筋
-   登坂力
-   下りのブレーキ能力

------------------------------------------------------------------------

## 8-2. ステップアップ

### 方法

1.  30〜40cm程度の台を用意
2.  片足を台に乗せる
3.  台上の脚を主体に身体を持ち上げる
4.  後ろ脚で強く蹴りすぎない
5.  ゆっくり元に戻る

### 回数

-   8〜12回 × 3セット / 脚

### 目的

急登時の動きに近く、臀部・大腿部の登坂力を作る。

------------------------------------------------------------------------

## 8-3. ルーマニアンデッドリフト

### 方法

1.  膝を軽く曲げる
2.  背中を安定させる
3.  お尻を後ろへ引く
4.  ハムストリングが伸びる位置まで上体を倒す
5.  臀部を締めながら元に戻る

### 回数

-   8〜12回 × 3セット

### 目的

-   ハムストリング
-   臀筋
-   股関節伸展力
-   登りの推進力

------------------------------------------------------------------------

## 8-4. ステップダウン

50kmトレイルでは特に重要。

### 方法

1.  20〜30cm程度の台に片脚で立つ
2.  反対側の踵を床へ近づける
3.  支持脚の膝を3〜4秒かけてゆっくり曲げる
4.  コントロールしたまま下降
5.  元の位置へ戻る

### 回数

-   8〜12回 × 2〜3セット / 脚

### 目的

下りで大腿四頭筋が行う「伸ばされながらブレーキをかける」動作への耐性を作る。

自重から開始し、慣れたらダンベルや5〜10kg程度のリュックなどで徐々に荷重する。

------------------------------------------------------------------------

## 8-5. 片脚カーフレイズ

### 方法

階段などの段差を使用する。

1.  前足部だけを段差に乗せる
2.  片脚立ちになる
3.  踵を十分下げる
4.  1〜2秒程度で最大まで上げる
5.  上で約1秒停止
6.  2〜3秒かけて下降

### 回数

-   15〜25回 × 3セット / 脚

20〜25回が余裕になれば荷重する。

### 目的

-   ふくらはぎ
-   足首周辺
-   長時間の登り・下りへの耐性

------------------------------------------------------------------------

## 8-6. サイドプランク

### 方法

-   頭から足まで一直線
-   腰を落とさない
-   骨盤を安定させる

### 回数

-   30〜60秒 × 2セット / 左右

### 目的

不整地での体幹・骨盤の安定。

------------------------------------------------------------------------

## 9. 40分筋トレメニュー

1.  ウォームアップ：約5分
2.  ブルガリアンスクワット：10回 × 3 / 脚
3.  ステップアップ：10回 × 3 / 脚
4.  ルーマニアンデッドリフト：10回 × 3
5.  ステップダウン：10回 × 2 / 脚
6.  片脚カーフレイズ：15〜20回 × 3 / 脚
7.  サイドプランク：45秒 × 2 / 左右

セット間休憩：

-   約60〜120秒

原則として限界まで追い込まない。

翌日のランニング能力を大きく落とすほどの筋肉痛を毎回発生させない。

------------------------------------------------------------------------

# 10. 食事

50kmレースへ向けて、体重を減らすために極端に食事を制限しない。

基本：

-   炭水化物：米、麺、芋、果物など
-   タンパク質：肉、魚、卵、大豆、乳製品など
-   野菜・果物を確保
-   トレーニング量が多い日は炭水化物を増やす

タンパク質は1日約1.6g/kgを一つの目安とする。

体重60kgの場合：

**約95〜100g/日**

程度。

------------------------------------------------------------------------

# 11. レース補給のトレーニング

50kmでは補給能力そのものをトレーニングする。

ロング走で、

-   40〜50g炭水化物/時
-   60g/時
-   70g/時
-   80〜90g/時

と段階的に増やし、自分の胃腸が処理できる範囲を確認する。

本番直前に新しい補給食を試さない。

2月の模擬レースでは、

-   本番用ザック
-   シューズ
-   ウェア
-   水分
-   ジェル
-   固形物
-   電解質

まで本番に近い条件でテストする。

------------------------------------------------------------------------

# 12. レース戦略の基本

50kmでは序盤の順位を取りに行きすぎない。

基本イメージ：

-   0〜15km：かなり抑える
-   15〜30km：一定出力
-   30km以降：周囲が落ちてきたところで維持または徐々に上げる

目標は、

**「30km地点からも登れる脚を残す」**

こと。

50km/D+2,400mでは、平地スピードだけでなく「後半でも登り続けられる能力」と「下りで脚を壊さない能力」が順位に大きく影響する。

------------------------------------------------------------------------

# 13. 今後記録したい指標

今後のトレーニングでは以下を記録する。

1.  週走行距離
2.  週累積標高
3.  ロング走距離
4.  ロング走累積標高

8.  体重
9.  睡眠
10. 主観的疲労度
11. ロング走での炭水化物摂取量（g/h）
12. 水分摂取量

これらを使い、2027年3月までトレーニング内容を随時調整する。

------------------------------------------------------------------------

## 現時点での最重要ポイント

現在の走力では、10kmのスピードを極端に上げることよりも、

**週15km程度の走行量を、安全に週40〜55km程度まで引き上げること**

の優先度が高い。

その上で、

**有酸素能力 ＋ 登坂力 ＋ 下り耐性 ＋ 補給能力**

を組み合わせ、50km後半でも走れる身体を作る。

## 方針

元の計画（[reference/original-plan-other-ai.md](../reference/original-plan-other-ai.md)）の方向性は引き継ぐ。変えた点は次の4つ。

1. **距離ではなく、時間と累積標高（D+）で管理する。** 距離は参考値にとどめる。トレイルでは同じ10kmでも負荷がまったく違うため。
2. **ロング走は「直近30日の最長の1.1倍以内」にする。** 1回のランの距離が直近30日の最長を10%以上超えると、故障リスクが上がるという研究がある（[Frandsen et al. 2025, BJSM](https://findresearcher.sdu.dk/ws/files/295073070/1203.full.pdf)）。研究は距離で測っているので、トレイルで時間に置き換えるのはこちらの推論。
3. **膝と太もも前の弱点を最優先で鍛える。** 下りの刺激を毎週入れ、筋トレは週2回にする。
4. **定点テストで伸びを測り、計画を直す。**

ロングの出発点について：10/3に5時間10分走っているので、ロング走の時間そのものはすでにある程度耐えられる。足りないのは週あたりの量（現在約15km/週）と、後半の下りに耐える脚。前半のロングはあえて3〜3.5時間に抑え、平日の量を増やすことを優先する。

## 1週間の基本形（週4日）

| 曜日 | 内容 | 目的 |

| 月 | 休み | |
| 火 | Easy 45〜60分＋筋トレA | 有酸素の土台、脚の筋力 |
| 水 | 休み | |
| 木 | 里山の坂反復（標高差約150m × 本数） | 登る力、下りに強い脚 |
| 金 | 休み | |

仕事の都合で曜日は動かしてよい。ただし「きつい練習の翌日は楽な日か休み」は守る。

## 里山の坂反復（木曜）

| 時期 | 本数 | 登り | 下り |
|---|---|---|---|
| 基礎期（W2〜W8） | 2→6本 | 会話ぎりぎり（6〜7/10） | 小さい歩幅で静かに着地。レースより少し遅く |
| 強化期（W10〜W17） | 5〜7本 | 8/10（インターバル） | ジョグでつなぐ |
| 特異期（W19〜W21） | 4〜6本 | 8/10 | **レースペースで下る** |

1本で約150m登る。6本なら約900mになり、平日だけで週のD+をかなり稼げる。

## 下りに強い脚をつくる（膝・太もも前の対策）

- 下り走で筋肉がダメージを受けると、次の下りでは傷みにくくなる（繰り返し効果）。ただしこの効果は、30分の下り走1回の場合、9週間空けると消えたという報告がある（[Downhill Running review, PMC](https://pmc.ncbi.nlm.nih.gov/articles/PMC7674385/)）。**下りの刺激は毎週、少なくとも2週に1回は入れる。**
- 下りの量は、木曜の里山の本数で少しずつ増やす。
- 強化期からは、ロング走の最後の1時間に下りを入れて「疲れた脚で下る」練習をする。本番で脚が終わるのは後半なので。
- 膝の痛みは場所も記録する（お皿のまわり／外側／内側／裏）。同じ場所が2日続けて3/10以上なら、強い練習と下りを休んで相談する。

## 筋トレ

40代は筋力が落ちやすいので週2回にする。WHOは成人に週2日以上の筋力トレーニングを勧めている（[WHO 身体活動ガイドライン](https://www.who.int/publications/i/item/9789240015128)）。

### 筋トレA（火曜・約35分）

| 種目 | 回数 | ねらい |
|---|---|---|
| スロー・ステップダウン（20〜30cmの台、3〜4秒かけて下ろす） | 3×8〜10／脚 | 下りでブレーキをかける太もも前。いちばん大事 |
| ブルガリアンスクワット（3秒で下ろす） | 3×8〜10／脚 | 登りと下りの両方 |
| 片脚ルーマニアンデッドリフト | 3×8／脚 | お尻・もも裏。登りの推進力 |
| ウォールシット（壁にもたれて空気椅子） | 3×30〜45秒 | 膝を曲げ伸ばしせずに太もも前を鍛える |
| バンドで横歩き（またはクラムシェル） | 2×15歩／方向 | お尻の横。下りで膝が内側に入るのを防ぐ |
| 片脚カーフレイズ（段差で） | 3×15〜20／脚 | ふくらはぎ・足首 |

### 筋トレB（日曜・約15分）

ステップダウン 2×10／脚、片脚カーフレイズ 2×20／脚、サイドプランク 2×40秒／左右。

### 進め方

- W1〜W2は自重・2セットで始め、強い筋肉痛を作らない
- 12回が楽になったら荷物を足す（リュックに5kg → 10kg）
- 回復週は筋トレAだけを軽く。重い筋トレはW21が最後、W23で終了

## 補給の練習

本番は9〜10時間かかる見込み。ロング走で炭水化物の量を少しずつ増やす。

| 時期 | 炭水化物 |
|---|---|
| W2〜W4 | 40〜50g/時 |
| W6〜W12 | 60g/時 |
| W13〜W17 | 60〜70g/時 |
| W19〜W21 | 70〜80g/時（本番と同じ補給食で） |

アプリに g/時・水分・胃腸の調子（0〜3）を記録する。本番の直前に新しい補給食は試さない。

## 定点テスト（W2・W6・W10・W15・W19の木曜）

1. **里山の登りタイム**：アップ15分のあと、決まった登り1本を一定の強さで全力に近く。タイムと平均心拍を記録する → 登坂速度（m/時）＝ 標高差 ÷ 時間
2. **下りへの耐性**：その日の里山の本数と、**翌々日の太もも前の張り（0〜10）**を記録する

テストの数値が伸びていなければ、次の4週の内容を見直す。

## 自動で知らせるルール（アプリの警告）

| ルール | 警告 |
|---|---|
